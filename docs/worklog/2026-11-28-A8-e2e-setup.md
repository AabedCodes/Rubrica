- **`frontend/e2e/model-text.spec.ts`,** three browser tests:
  - **T-09:** a released grade whose model-written feedback contains `![x](https://canary.example/?d=CANARY-T09-4e2f)` shows "[image removed: x]". There is no `<img>` in `main`, and the request log has no request to `canary.example`.
  - **T-10:** the same feedback contains `<script>window.CANARY_T10=1</script>`, `<img src=x onerror="window.CANARY_T10=1">` and `[click](javascript:window.CANARY_T10=1)`. The test checks that:
    - the link is plain text, and clicking it does nothing;
    - there's no `<script>` in `main` and no `[onerror]` anywhere;
    - `window.CANARY_T10` is undefined;
    - no page errors occur.
  - **T-09 (chat):** D2's fixture reply image (`CANARY-T09-0c97`) is never requested.
- **Mock seed:** Student Two's released Assignment 0 feedback now carries these canaries (harmless markers only).
- **Commands:** `npm run e2e` and `make e2e`. Vitest now excludes `e2e/`; `tsconfig` type-checks it.

## How

The mock lives in the page, so each test loads once at a protected URL, signs in on the redirect, and then only clicks; a reload would reset the mock world. Requests are recorded with `page.on("request")` from the start of the test.

## Decisions

| Decision | Alternatives considered | Why |
|---|---|---|
| Tests in `frontend/e2e/`, not `tests/e2e/` | `tests/e2e/` as in §1's layout | Specs outside `frontend/` can't resolve `@playwright/test` (installed in `frontend/node_modules`). `tests/e2e/` stays for the full-stack `test_main_workflow.spec.ts` the plan names |
| Run against the mock dev server | Production build under `vite preview` (has the CSP) | The production build has no mock and no backend yet, so there is nothing to render. The CSP check moves to the full-stack test (`web` sets the headers) |
| Not part of `make test` | Add it | Browser tests need a downloaded browser and a dev server; `make e2e` runs them on demand |
| Browser installed with `npx playwright install chromium`, after A approved it | Install Google Chrome and use `channel: "chrome"` | Neither Chrome nor Edge is installed on this machine. The download (Chrome for Testing 159.0.8154.6, its headless shell, ffmpeg, from `cdn.playwright.dev`) went into `~/Library/Caches/ms-playwright`, outside the repo. The assistant waited for A's explicit OK first |
| Sabotage check on top of the pass | Trust a first-run pass | A browser test that has never failed proves little. Breaking `SafeMarkdown` showed each test catches the regression it is meant for (see Evidence) |
| `frontend/test-results/` and `frontend/playwright-report/` in `.gitignore` | Commit or delete them by hand | Playwright writes them on every run |
